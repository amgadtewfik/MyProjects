## 🔴 Quick Wins (1-2 hours each)

### 1. Edit Button Already Works — Just Wire It
The `editApplication(idx)` function exists and works, but there's no edit button in the table rows. The `✏️` emoji button is already in the HTML — just need to ensure it's calling the right function. **This is a 5-minute fix.**

### 2. Keyboard Shortcuts
- `s` → focus search bar
- `a` → open quick add (auto-focus company field)
- `n` → open full add modal
- `Esc` → close modal
- `Ctrl+Enter` → submit from modal

This makes adding 10+ applications in a session dramatically faster.

### 3. Inline Note Editing
Currently, editing a note requires opening the modal. Add a click-to-edit on the notes cell in the table — small textarea that auto-saves on blur.

### 4. Quick Add from Pending Jobs
The `/api/pending-jobs` endpoint already returns filtered, ranked jobs from LinkedIn. Add an "Apply ✓" button next to each pending job that auto-fills the quick-add form and saves — one click instead of copy-pasting company + title.

### 5. Smart Follow-up Defaults
- **Applied** → follow-up in 14 days (already done)
- **Pre-Interview** → follow-up in 7 days
- **Wait For Response** → follow-up in 5 days
- **Interview** → follow-up in 3 days (post-interview thank-you)
- When status changes, auto-update follow-up date

## 🟡 Analytics & Insights (half-day each)

### 6. Source Performance Dashboard
You already track `source` (LinkedIn, Quick Add, Manual). Add a breakdown:
- Response rate by source
- Interview rate by source
- Average days-to-response by source

This tells you where to focus your energy.

### 7. Company Repeat Detection
Flag companies you've applied to multiple times (Eaton appears twice in your data already). Show previous application status and notes when adding a new one to the same company.

### 8. Time-to-Conversion Metrics
| Metric | Formula |
|--------|---------|
| Applied → Response | Days until status changes from Applied |
| Applied → Interview | Days until Interview status |
| Pipeline conversion % | Interview / Applied × 100 |

You already have the date data — this is just a render function.

### 9. Application Velocity Chart
A simple bar chart showing applications per week (you already have weekly stats) plus a trend line. Spot when you're slacking off.

### 10. Export to CSV
One button that serializes all applications as CSV. Useful for sharing with a career coach or importing into a spreadsheet.

## 🔵 Advanced (multi-day)

### 16. SQLite Migration
Replace `job_applications.md` with SQLite. Benefits:
- No regex parsing (current weakness: pipe `|` in notes breaks rows)
- Real queries (filter by date range, status, company)
- No row-count verification hacks
- Concurrent writes are safe
- Add 1 line of Python (`import sqlite3`, zero external deps)

You can keep the markdown export as a read-only view — best of both worlds.

### 17. Gmail Integration
Use Gmail API to auto-detect:
- Application confirmations → auto-add application
- Rejection emails → auto-set status to Rejected
- Interview scheduling emails → auto-set status to Interview + extract date

### 18. LinkedIn Auto-Importer
A small browser bookmarklet or extension that, when you click "Apply" on LinkedIn, sends the job details to your local tracker. This eliminates manual entry entirely.

### 19. Notification System
Desktop notifications (via Notification API) or email reminders for:
- Overdue follow-ups (daily at 9 AM)
- No applications added in 3 days (gentle nudge)
- Application milestones (🎉 50 applications!)

### 20. A/B Test Your Applications
Track which version of your resume/cover letter you used per application, then compare response rates. Data-driven career strategy.
