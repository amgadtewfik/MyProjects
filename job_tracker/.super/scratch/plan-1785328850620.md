## 3 Approaches, Ranked by Complexity

### 🟢 Level 1: Bookmarklet (1 hour, zero infra)

A browser bookmarklet — a tiny JS snippet you save as a bookmark. When you're on a LinkedIn job listing, click it. It extracts the job title, company, location, and URL from the page and POSTs them to your local server.

**Requirements:**
- A new endpoint `POST /api/import-job` that accepts `{ title, company, location, url }` and appends to the report file
- A bookmarklet snippet (~15 lines of JS)
- CORS or same-origin (you're on localhost, so fine)

**Pros:** Works immediately, no API keys, no ToS issues, no login automation
**Cons:** You still browse LinkedIn manually and click per-job

### 🟡 Level 2: LinkedIn RSS Feed (half-day, no API key)

LinkedIn job search results have RSS feeds (e.g., `https://www.linkedin.com/jobs/search/?keywords=senior+developer&location=montreal&rss=true`). You can poll this periodically and parse new listings.

**Requirements:**
- `requests` or `urllib` to fetch the RSS feed
- XML parsing (built-in Python `xml.etree.ElementTree`)
- A scheduler / cron job to poll daily
- Deduplication logic (don't re-import jobs you've already seen)

**Pros:** No API key, no ToS scraping, completely above-board
**Cons:** RSS feed data is limited (title, company, location, link — no fit score)

### 🔴 Level 3: Full Browser Automation (1-2 days, high maintenance)

Use Playwright or Puppeteer to log into LinkedIn, run your saved searches, extract job cards with all metadata (fit score, skills match, posted date), and auto-import.

**Requirements:**
- `pip install playwright` (Python) or `npm i puppeteer`
- LinkedIn credentials stored locally (security risk)
- A headless browser binary (~300MB)
- Login session management (handles 2FA, captchas)
- Regular maintenance (LinkedIn changes DOM ~monthly)

**Pros:** Full metadata including fit score, skills match, company page data
**Cons:** Against LinkedIn ToS, fragile, high maintenance, your account could be flagged

The bookmarklet code would look like this:

```javascript
javascript:(function(){
  const title = document.querySelector('.job-title')?.innerText?.trim() || '';
  const company = document.querySelector('.job-company')?.innerText?.trim() || '';
  const location = document.querySelector('.job-location')?.innerText?.trim() || '';
  const url = window.location.href;
  fetch('http://localhost:8000/api/import-job', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({title, company, location, url})
  }).then(r => r.json()).then(d => alert('Imported: ' + d.company));
})();
```
